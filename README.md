# vista-linoleum-gen
# 🏷️ Linoleum Specs Generator (Pro Edition)

**Professional technical label generator for flooring retail. Fast, clean, and ready for A4 printing.**

---

### 🌍 English Description
Automate the creation of technical labels for linoleum. This tool generates a professional layout with all necessary specifications.

* **Full Tech Specs:** Manufacturer, collection, total thickness, wear layer protection, and weight (kg/m²).
* **Live Preview:** Real-time updates as you type.
* **Print Optimized:** Automatically fits 4 identical labels onto a single A4 sheet.

---

### 🇺🇦 Опис (Українська)
Професійний інструмент для генерації технічних характеристик лінолеуму. Створено для швидкої підготовки цінників безпосередньо у відділі покриття.

#### 🚀 Можливості:
* **Повний набір:** Виробник, колекція, загальна товщина, захисний шар та вага.
* **Попередній перегляд:** Результат у реальному часі під час заповнення полів.
* **Розумний друк:** Автоматично формує макет із 4 картками на одному аркуші А4.
